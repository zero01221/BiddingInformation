铁塔招标信息 · macOS 本机使用说明
========================================

【macOS 版：本机独立闭环】
  本包（BiddingInformation-mac.zip）解压即用，抓取、落库、生成、查看，
  全部只在这一台 mac 上完成：不需要 Windows、不需要同步盘、不需要第二台电脑、不需要 VPN。
  另有 Windows 版独立分发包，两个包互不依赖、互不混装脚本。
  唯一允许安装的是「一点简单环境」（Python 3 + requirements.txt），且只需装一次。

【两条命令，职责分离】
  1) 更新数据.command   双击 → 抓取并生成 output/index.html 等全部产物（唯一会写数据的入口）
  2) 查询.command       双击 → 只用系统自带 open 打开页面，零依赖、不抓取、不联网、不改数据
  · 打开_mac.command 是「查询.command」的兼容别名，内容等价，给旧书签用。
  · 首次使用：先双击「安装环境.command」创建 .venv 并装依赖（只需一次），
    之后每天重复「更新数据 → 查询」这一对即可。
  · 环境自检.command：只读检查 Python / 依赖 / 配置 / 历史库 / 产物 / 各源连通性。
  · 试抓测试.command：逐源真实联网试抓并报告每源条数，不写库、不写产物。
    想确认这台 mac 能否正常抓取，先跑这两条，再跑「更新数据」。

【最简单的用法（推荐，零依赖）】
  直接双击本目录的「铁塔招标信息.html」，或双击仓库根目录 output/index.html。
  用 Safari 或 Chrome 打开即可，页面数据已全部内嵌在 HTML 里：
  不需要 Python、Node、Homebrew，不需要联网，不需要 VPN，不需要任何构建步骤。
  只想看现有数据？这一条路径完全不用装环境、不用跑任何 .command。

【首次运行 .command 的提示】
  · 提示没有权限：在「终端」执行一次 chmod +x *.command
  · 被 Gatekeeper 拦截：Finder 里右键该文件 → 「打开」→ 再点「打开」。
  · 窗口结束时停在「按任意键关闭窗口…」，按任意键关闭。
  · 所有 .command 均为 UTF-8 无 BOM、LF 换行（由 .gitattributes 固定），
    克隆到 mac 后不会出现 bad interpreter。
  · 依赖缺失时「更新数据」会打印可操作的中文指引，不会静默失败。

【关于 file:// 限制】
  本页数据已内联，不通过 fetch 读取 data.json，因此 Safari/Chrome 以 file://
  打开时不会遇到跨域（CORS）报错，也不需要启动本地服务器。
  请勿把 HTML 用「文本编辑」或 Word 打开，务必用浏览器。

【页面能做什么】
  · 三类筛选可叠加取交集：地区（多选，默认仅「云南」，可勾多省或选「全部（全国）」）、
    日期区间（起始不能晚于结束，非法区间会自动纠正）、文件名关键字。
  · 每条显示四字段：文件名 / 日期 / 来源 / 摘要（缺失有明确占位）。
  · 每条两个按钮：「跳转出处」打开原站公告；「下载源招标文件」按 L1~L4 档位下载。
  · 公告类型只是标签，不参与筛选；所有类型公告都收录。
  · 顶部显示「数据更新时间 / 数据截至」，超过 2 天未更新会标黄提示。

【macOS 下载行为（与 Windows 不同，这是有意的兼容处理）】
  Safari 对 download 属性的支持与 Chrome 有差异，因此本页在 macOS 上
  点击「下载源招标文件」会先在新标签打开目标文件，并给出明确的「另存为」引导：
    菜单栏「文件 → 存储为…」，文件名用提示里给出的中文名（UTF-8，不会乱码）。
  这样不会出现「点了没反应」或静默失败。若浏览器拦截了新标签，请允许弹出窗口，
  或改用「跳转出处」到原站查看。
  提示中的 UTF-8 filename*（RFC 5987）编码供将来在线部署时设置下载头使用。

【下载档位说明】
  L1 原始文件     原站附件直链
  L2 源文件副本   应用侧预存副本（../attachments/）
  L3 详情页快照   原站无下载时提供快照（../snapshots/），页面会明确说明
  L4 无法下载     按钮禁用并提示「该来源不提供下载，请前往出处查看」，
                  不伪造文件、不产生 404、不静默失败

【每天怎么更新】
  在本机双击「更新数据.command」即可，国内站点 mac 直连可达，抓数不需要 VPN。
  它会采集 → 落库 → 原子写生成 output/index.html、data.json、RSS 与 win/mac 平台包；
  失败时保留上一版产物并给出中文提示，不会破坏已有页面。
  生成后双击「查询.command」，或刷新已打开的页面，就能看到新的「数据截至」。

【可选：每天 08:00 自动更新（默认不启用）】
  主动双击「安装每日更新.command」才会安装 launchd 定时任务，不装就绝不会自动运行。
  它把 mac/每日自动更新.plist 里的 {{PROJECT_DIR}} 替换为本机真实绝对路径，
  生成 ~/Library/LaunchAgents/com.biddinginformation.dailyupdate.plist 并 launchctl load。
  关闭：launchctl unload -w ~/Library/LaunchAgents/com.biddinginformation.dailyupdate.plist
        然后删除该 plist 文件。
  日志：output/launchd.out.log 与 output/launchd.err.log。

【目录里的其它文件】
  · ../index.html        仓库根目录主页面（与本目录页面数据相同）
  · ../data.json         分离数据产物（供调试，页面本身不依赖它）
  · ../bidding_feed.xml  RSS 订阅源
  · ../bidding_history.db SQLite 历史库（请保留，不要删除）

【常见问题】
  Q：为什么很多条是 L4？
  A：历史数据没有附件直链或快照文件，按规则诚实标注不可用，请点「跳转出处」。
  Q：页面提示「数据已超过 2 天未更新」？
  A：请双击「更新数据」后刷新本页，页面顶部「数据截至」会同步变化。
  Q：提示「缺少运行依赖」？
  A：双击「安装环境.command」（首次），或按终端提示执行 pip3 install -r requirements.txt。
