铁塔招标信息 · macOS 离线使用说明
========================================

【最简单的用法（推荐，零依赖）】
  直接双击「铁塔招标信息.html」，或双击仓库根目录 output/index.html。
  用 Safari 或 Chrome 打开即可，页面数据已全部内嵌在 HTML 里：
  不需要 Python、Node、Homebrew，不需要联网，不需要 VPN，不需要任何构建步骤。

【一键打开脚本（可选）】
  仓库根目录有「打开_mac.command」，双击它会执行 open ./output/index.html。
  · 首次使用可能需要在终端执行一次：chmod +x 打开_mac.command
  · 若被 Gatekeeper 拦截：在 Finder 里右键该文件 → 「打开」→ 再点「打开」。
  · 它不调用 Python、不联网、不修改任何数据；最稳妥的方式仍是直接双击 HTML。

【关于 file:// 限制】
  本页数据已内联，不通过 fetch 读取 data.json，因此 Safari/Chrome 以 file://
  打开时不会遇到跨域（CORS）报错，也不需要启动本地服务器。
  请勿把 HTML 用「文本编辑」或 Word 打开，务必用浏览器。

【页面能做什么】
  · 三类筛选可叠加取交集：地区（默认「云南优先」，可切「全部（全国）」）、
    日期区间、文件名关键字。
  · 每条显示四字段：文件名 / 日期 / 来源 / 摘要（缺失有明确占位）。
  · 每条两个按钮：「跳转出处」打开原站公告；「下载源招标文件」按 L1~L4 档位下载。
  · 公告类型只是标签，不参与筛选；所有类型公告都收录。
  · 顶部显示「数据更新时间 / 数据截至」，超过 2 天未更新会标黄提示。

【macOS 下载行为（与 Windows 不同，这是有意的版本区分）】
  Safari 对 download 属性的支持与 Chrome/Edge 有差异，因此本页在 macOS 上
  点击「下载源招标文件」会先在新标签打开目标文件，并给出明确的「另存为」引导：
    菜单栏「文件 → 存储为…」，文件名用提示里给出的中文名（UTF-8，不会乱码）。
  这样不会出现「点了没反应」或静默失败。若浏览器拦截了新标签，请允许弹出窗口，
  或改用「跳转出处」到原站查看。
  提示中的 UTF-8 filename*（RFC 5987）编码供在线部署时设置下载头使用。

【下载档位说明】
  L1 原始文件     原站附件直链
  L2 源文件副本   应用侧预存副本（output/attachments/）
  L3 详情页快照   原站无下载时提供快照（output/snapshots/），页面会明确说明
  L4 无法下载     按钮禁用并提示「该来源不提供下载，请前往出处查看」，
                  不伪造文件、不产生 404、不静默失败

【每天怎么更新】
  mac 端不抓取、不生成数据（这是设计，不是限制）。数据只在 Windows 生产端
  每日由 update.bat 生成，再通过同步盘 / 文件传输 / 局域网 / U 盘把
  output/ 里的新文件覆盖到本机，刷新浏览器即可看到新数据与新的「数据截至」。
  若用同步盘，日常 0 步；手动通道每天 1 步（覆盖文件 + 刷新）。
  终端访问全流程不会请求任何境外在线地址，也不依赖 GitHub Pages。

【目录里的其它文件】
  · ../index.html        根目录主页面（与本目录页面数据相同）
  · ../data.json         分离数据产物（供可选在线部署/调试，页面本身不依赖它）
  · ../bidding_feed.xml  RSS 订阅源
  · ../bidding_history.db SQLite 历史库（请保留，不要删除）

【常见问题】
  Q：为什么很多条是 L4？
  A：历史数据没有附件直链或快照文件，按规则诚实标注不可用，请点「跳转出处」。
  Q：页面提示「数据已超过 2 天未更新」？
  A：说明还没拿到最新产物；请从 Windows 端或同步盘重新覆盖 output/index.html。
