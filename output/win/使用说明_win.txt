铁塔招标信息 · Windows 离线使用说明
========================================
【Windows 版：本机独立闭环】
  本包（BiddingInformation-win.zip）解压即用，抓取、落库、生成、查看
  全部只在这一台 Windows 上完成，不需要 mac、不需要同步盘、不需要 VPN。
  另有 macOS 版独立分发包，两个包互不依赖、互不混装脚本。

【三条命令，职责分离】
  1) 安装环境.bat   首次一次：创建 .venv 并安装 requirements.txt
  2) 更新数据.bat   双击 → 抓取并生成 output\index.html 等产物（唯一会写数据的入口）
  3) 查询.bat       双击 → 用默认浏览器打开页面，零依赖、不抓取、不联网、不改数据
  · 环境自检.bat / 试抓测试.bat：只读检查环境与逐源试抓，不写库、不写产物。
  · update.bat 为可选备用入口（含 git push 与 BIDDING_SYNC_DIR 同步目录），主流程不需要它。


【最简单的用法】
  双击同目录下的「铁塔招标信息.html」，或双击仓库根目录的 output/index.html。
  推荐浏览器：Chrome / Edge（也可用 Firefox）。无需安装 Python、Node 或任何插件，
  无需联网、无需 VPN，页面数据已全部内嵌在 HTML 里。

【页面能做什么】
  · 三类筛选可叠加取交集：地区（多选，默认仅「云南」，可勾多省或选「全部（全国）」）、
    日期区间（起始不能晚于结束，非法区间会自动纠正）、文件名关键字。
  · 每条显示四字段：文件名 / 日期 / 来源 / 摘要（缺失会显示「暂无…」占位）。
  · 每条两个按钮：「跳转出处」打开原站公告；「下载源招标文件」按 L1~L4 档位下载。
  · 公告类型只是标签，不参与筛选，所有类型公告都会收录。
  · 页面顶部显示「数据更新时间 / 数据截至」。数据截至超过 2 天会标黄提示；
    离线文件不会自己变新，需要重新获取产物文件覆盖。

【下载档位说明】
  L1 原始文件：直接下载原站附件，保留中文文件名。
  L2 源文件副本：下载应用侧预存的副本（位于 output/attachments/）。
  L3 详情页快照：原站不提供下载时，下载保存的详情页快照（output/snapshots/）。
  L4 无法下载：按钮禁用并明确提示「该来源不提供下载，请前往出处查看」，
      不会伪造文件、不会出现 404 或点了没反应。

【中文文件名】
  Chrome / Edge 下点击下载按钮会用原始中文名保存，不会乱码。
  如果浏览器另存为时名字不对，可手动改成按钮提示里给出的文件名。

【每天怎么更新】
  1. 双击仓库根目录的「更新数据.bat」，或把它加入「任务计划程序」每日定时触发。
  2. 它会：抓取与处理 → 落库 → 重新生成 output\index.html / data.json / RSS / 平台包。
     产物采用原子写，全部数据源失败时保留上一版页面，不会生成半成品。
  3. 完成后双击「查询.bat」看结果；页面顶部「数据截至」会同步更新。
  4. 可选备用入口 update.bat 才涉及 git push 与 BIDDING_SYNC_DIR 同步目录（未设置则跳过）。

【验证能否正常抓取】
  双击「环境自检.bat」看环境/依赖/各源连通性；双击「试抓测试.bat」逐源真实试抓并报告条数。
  两者都只读，不写数据库、不写产物，可反复运行。

【目录里的其它文件】
  · ../index.html        根目录主页面（与本目录页面数据相同）
  · ../data.json         分离的数据产物（供可选在线部署/调试，页面本身不依赖它）
  · ../bidding_feed.xml  RSS 订阅源
  · ../bidding_history.db SQLite 历史库（请保留，不要删除）
  · ../snapshots/  ../attachments/  快照与附件副本（按去重键命名）

【常见问题】
  Q：打开是空白或提示数据解析失败？
  A：确认文件完整（不要只复制一半），并用 Chrome/Edge 打开；不要用 Word/WPS 打开。
  Q：为什么很多条是 L4？
  A：历史数据没有附件直链或快照文件，按规则诚实标注为不可用，请点「跳转出处」。
