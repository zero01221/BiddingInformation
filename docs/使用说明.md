# 铁塔招标信息 · 使用说明（面向用户）

> 本版提供 **win / mac 两个独立包，各自单机本地闭环**：抓取、生成、查看全部只在同一台电脑上完成。
> 不需要另一台机器、不需要同步盘、不需要第二台电脑、不需要 VPN。
> 唯一允许安装的是「一点简单环境」（Python 3 + `requirements.txt`），且只需装一次。
> 最终形态为「离线优先的零构建纯静态 HTML」，选型见 [ARCHITECTURE.md](ARCHITECTURE.md)，
> 运行时形态以 [README.md](../README.md) 与本文为准。

---

## 1. 三条命令，各干什么

| 步骤 | 命令（在仓库根目录**双击**） | 频率 | 会不会联网 / 改数据 |
| --- | --- | --- | --- |
| ① 一次性准备 | `安装环境.command` | 只做一次 | 装依赖到项目内 `.venv`，不碰数据 |
| ② **更新数据** | `更新数据.command` | 每天 / 想更新时 | **会**抓取、会写数据库、会生成产物 |
| ③ **查询** | `查询.command` | 随时 | **不会**：零依赖，只 `open ./output/index.html` |

`打开_mac.command` 是 `查询.command` 的兼容别名，内容等价，给旧书签用。
两个入口职责完全分离：想更新就点②，只想看就点③，互不干扰。

### 1.1 第一次使用（三步）

1. **装 Python 3**（一次性）：到 Python 官网 `python.org` 下载 macOS 安装包（`.pkg`）双击安装；
   或者已装 Homebrew 时在「终端」执行 `brew install python3`。
2. **双击 `安装环境.command`**：自动在项目内创建 `.venv/` 并安装
   `requests / PyYAML / beautifulsoup4 / lxml / tenacity`。看到「安装完成」即可关掉窗口。
3. **双击 `更新数据.command`**：跑一次抓取并生成 `output/index.html`。
   完成后双击 **`查询.command`** 看数据；以后每天重复这一对即可。

> 如果你**只想查看现有数据**：直接双击 `output/index.html`，
> 或者双击 `查询.command`。这两条路径**完全不需要 Python、不需要联网、不需要安装任何东西**。

### 1.2 双击 `.command` 的首次提示

- 提示「没有权限」：在「终端」里执行一次 `chmod +x *.command`（或单个文件名）；
- 被 Gatekeeper 拦截：Finder 中**右键该文件 → 打开 → 再点「打开」**；
- 窗口会停在「按任意键关闭窗口…」，方便看清中文提示，按任意键即关闭；
- 仓库里的 `.command` 均为 UTF-8 无 BOM、LF 换行，并由 `.gitattributes` 固定，
  克隆到 mac 后不会出现 `bad interpreter`。

### 1.3 依赖缺失会怎样

`更新数据.command` 会先找 `.venv/bin/python` → `python3` → `python`，
再检查五个依赖库是否都能导入。缺任何一个都会**明确打印中文指引**（例如
`pip3 install -r requirements.txt`，或「首次运行请先执行 安装环境.command」），
不会静默失败、不会生成半成品。抓取失败时会提示「本次采集失败，已保留上一版产物」，
因为产物是原子写，上一版 `output/index.html` 不会被破坏。

### 1.4 两个分发包与验证抓取

`packages/` 下有两个免安装包，解压即用：**`BiddingInformation-mac.zip`**（只含 `.command`）与
**`BiddingInformation-win.zip`**（只含 `.bat`）。两者都自带核心代码、配置、预生成页面与完整历史库，
Windows 版把本文中的 `.command` 换成同名 `.bat` 即可，命令职责完全一致。

Windows 若用系统自带解压后中文文件名乱码，请改用 7-Zip / Bandizip / WinRAR 解压。

想在自己电脑上确认「能不能正常抓取」，用这两条**只读**命令（不写数据库、不写产物，可反复跑）：

| 命令 | 作用 | 耗时 |
| --- | --- | --- |
| 双击 `环境自检.command`（Win：`环境自检.bat`） | 检查 Python / 五个依赖 / 配置 / 历史库 / 页面产物 / 每个数据源连通性 / 代理 | 秒级 |
| 双击 `试抓测试.command`（Win：`试抓测试.bat`） | 在上面基础上逐源**真实联网试抓**，逐源报告取回条数 | 数分钟 |

命令行等价：`python -m scripts.bidding_scraper.doctor` 与 `... --probe`。
输出用 `[通过]` / `[失败]` / `[注意]` 标注，末尾给出结论；某个源 0 条不影响其它源，
页面仍可看历史数据。正式写入数据请用「更新数据」，不要用自检命令。

## 2. 页面怎么用

用 Safari / Chrome 打开；**务必用浏览器**，不要用 Word / WPS / 文本编辑打开。
建议把 `output/index.html` 加入书签或 Dock，以后一键打开。

### 三类筛选（可叠加，取交集）

1. **地区（可多选）**：点「地区」按钮展开复选框面板，勾选任意多个省份，多选之间按「或」匹配；
   不勾任何省（或点「全部（全国）」）即看全国数据；点「仅云南」回到默认视图。
   全国数据始终全量入库，默认视图只是先筛云南，切换不会影响数据完整性。
2. **日期区间**：填「起始日期 / 结束日期」，结果 100% 落在区间内。
   **起始日期不能晚于结束日期**：日历控件会自动限制可选范围；若手动输入了非法区间，
   结束日期会自动对齐到起始日期并显示红色提示「起始日期不能晚于结束日期」。
3. **文件名关键字**：输入标题中的词（如「铁塔」「昆明」）做模糊匹配。

三者同时填写时取交集；点「重置」恢复默认云南视图并清空其它条件。

### 每条信息显示什么

- 四字段：**文件名 / 日期 / 来源 / 摘要**，缺失时显示「暂无摘要」「暂无来源」等明确占位；
- 地区标签（省 / 州市）、公告类型标签（**只作标签，不参与筛选**，所有类型公告都收录）；
- 「日期待核实」标签表示该条公告日期无法解析，但数据仍保留；
- 页面顶部：「数据更新时间」「数据截至」「总条数」「当前平台」；
- 页面底部：各数据源本次运行状态（条数 / 失败原因），单源失败不会影响其它源。

### 两个按钮

| 按钮 | 行为 |
| --- | --- |
| **跳转出处** | 打开库中保存的原始公告 URL；链接只允许 http/https，非法或缺失时按钮禁用并说明 |
| **下载源招标文件** | 按 L1~L4 档位下载，档位与文案直接显示在条目上 |

### 下载档位

| 档 | 你会得到 | 页面标注 |
| --- | --- | --- |
| L1 | 原站原始文件（保留中文名） | 原始文件 |
| L2 | 应用侧预存的源文件副本 | 源文件副本 |
| L3 | 详情页快照（HTML/文本） | 原站未提供文件下载，以下为详情页快照 |
| L4 | 按钮禁用，无文件 | 该来源不提供下载，请前往出处查看 |

L4 时**不会伪造文件、不会 404、不会点了没反应**，请改点「跳转出处」。
历史数据没有附件直链或快照文件，因此多数条目会显示 L4，这是诚实标注而非故障。

### 中文文件名与浏览器差异

macOS Safari 对 `download` 属性支持与 Chrome 有差异，页面会**在新标签打开目标文件**
并给出明确引导：菜单「文件 → 存储为…」，文件名用提示里给出的中文名（UTF-8）。
提示中还附有 RFC 5987 编码，供将来在线部署时设置下载头使用。这是有意的兼容处理，不是故障。
若浏览器拦截了新标签，请允许弹出窗口，或改用「跳转出处」。

## 3. 每天怎么更新（mac 本机）

### 3.1 手动更新（推荐）

双击 `更新数据.command`，它按顺序完成：

1. 采集已启用的数据源 → 相关性校验 / 地区打标 / 去重 / 下载档位判定；
2. 落库 `output/bidding_history.db`（历史全量保留，不会按公告日期删除）；
3. 重新生成 `output/index.html`、`output/data.json`、`output/bidding_feed.xml`
   以及 `output/win/`、`output/mac/` 平台包（**原子写**：校验通过才替换，失败保留上一版）。

国内站点 mac 直连可达，抓数不需要 VPN。生成完毕后双击 `查询.command`（或刷新已打开的页面）
就能看到新数据与新的「数据截至」。

### 3.2 可选：每天 08:00 自动更新（默认不启用）

只有主动双击 `安装每日更新.command` 才会安装，不装就绝不会自动运行：

1. 它把 `mac/每日自动更新.plist` 里的 `{{PROJECT_DIR}}` 替换为本机真实绝对路径
   （不硬编码任何其它机器的盘符路径）；
2. 生成 `~/Library/LaunchAgents/com.biddinginformation.dailyupdate.plist` 并执行 `launchctl load`；
3. 任务用 `StartCalendarInterval` 每天 08:00 触发、`RunAtLoad=false`，
   只调用本机的 `更新数据.command`；`查询.command` 永远不参与自动任务。

查看：`launchctl list | grep biddinginformation`。
关闭：`launchctl unload -w ~/Library/LaunchAgents/com.biddinginformation.dailyupdate.plist`，
然后删除该文件。日志在 `output/launchd.out.log` / `output/launchd.err.log`。

> 仍然可以直接双击 `output/index.html` 查看，无需任何脚本 —— 这是零依赖基线。
> 需要本地静态服务时（可选调试）才用 `python scripts/serve_web.py --port 8080`，
> 它只绑定 `127.0.0.1`，不对外提供访问。

## 4. 「数据截至」与新鲜度

- **数据更新时间**：本次产物生成时刻；**数据截至**：库中成功采集的最晚公告日。
- 数据截至超过 `offline.stale_days`（默认 **2** 天）时，页面会显示黄色提示。
- 离线 HTML **不会自动变新**：提示出现时，请**双击「更新数据」后刷新本页**，
  页面顶部「数据截至」就会变化。
- 本期**不做任何消息推送**，用户主动打开页面才看到更新；断网也能看最近一次数据。

## 6. 可选备用：Windows 入口（mac 用户可跳过）

`update.bat` 只是保留的 Windows 备用入口，行为不变，不运行它不影响 mac 本地方案：

- 它会尝试 `git push origin master`（**失败仅告警**，本地产物照常可用）；
- 设置环境变量 `BIDDING_SYNC_DIR`（或配置 `publish.sync_dir`）指向同步盘目录时才复制 `output/`，
  **未设置则跳过复制、不阻断**；
- `BIDDING_SYNC_DIR` 只属于这个备用入口，mac 本地方案**不需要**它，
  也不需要同步盘、文件传输、局域网或 U 盘。

## 7. 常见问题

**Q：打开是空白或提示「内联数据解析失败」？**
A：确认 HTML 文件完整（没有只复制一半），改用 Chrome / Edge / Safari 打开。

**Q：双击 `.command` 提示没有权限 / 被 Gatekeeper 拦截？**
A：终端里执行一次 `chmod +x *.command`；若被拦截，Finder 右键 → 打开 → 再点「打开」。
最简单的是干脆不跑脚本，直接双击 `output/index.html`。

**Q：提示「缺少运行依赖」？**
A：双击 `安装环境.command`（首次），或按终端提示执行 `pip3 install -r requirements.txt`。

**Q：为什么很多条目是 L4「无法下载」？**
A：历史数据没有附件直链，也没有保存过详情页快照。按规则不得伪造文件，
因此诚实标注为不可用。请点「跳转出处」到原站查看。

**Q：mac 上点下载只打开了新标签？**
A：这是 Safari 的有意降级行为，请按页面提示用「文件 → 存储为」保存，或改用 Chrome。

**Q：为什么页面还显示旧数据？**
A：离线文件不会自己更新。请**双击「更新数据」后刷新本页**；页面顶部「数据截至」会变化。

**Q：看到「所有数据源本次均失败」提示？**
A：产物保留了上一版，数据仍可读。请检查本机网络与日志，稍后重跑 `更新数据.command`。
