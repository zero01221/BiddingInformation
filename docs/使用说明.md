# 铁塔招标信息 · 使用说明（面向用户）

> 本说明面向**不装开发环境**的终端用户。数据生产只在 Windows 端进行；
> macOS 端只需要一个浏览器。最终形态为「离线优先的零构建纯静态 HTML」，
> 详见 [ARCHITECTURE.md](ARCHITECTURE.md)。

---

## 1. 第一次打开（3 秒可用）

| 平台 | 操作 | 备注 |
| --- | --- | --- |
| Windows | 双击 `output/index.html`（或 `output/win/铁塔招标信息.html`） | 推荐 Chrome / Edge |
| macOS | 双击 `output/index.html`（或 `output/mac/铁塔招标信息.html`） | Safari / Chrome 均可 |

- 不需要安装 Python、Node、Homebrew 或任何插件；
- 不需要联网、不需要 VPN，页面数据已全部内嵌在 HTML 里；
- 不要用 Word / WPS / 文本编辑打开，务必用浏览器；
- 建议把页面加入浏览器书签或 Dock，以后一键打开。

### macOS 可选：一键打开脚本

仓库根目录的 `打开_mac.command` 只执行 `open ./output/index.html`，不调用 Python、不联网、
不改动任何数据。首次使用可能需要：

```bash
chmod +x 打开_mac.command
```

若被 Gatekeeper 拦截，在 Finder 中**右键该文件 → 打开 → 再点「打开」**。
最稳妥的路径其实是**根本不用脚本，直接双击 HTML**。

## 2. 页面怎么用

### 三类筛选（可叠加，取交集）

1. **地区（可多选）**：点「地区」按钮展开复选框面板，勾选任意多个省份，多选之间按「或」匹配；
   不勾任何省（或点「全部（全国）」）即看全国数据；点「仅云南」回到默认视图。
   全国数据始终全量入库，默认视图只是先筛云南，切换不会影响数据完整性。
2. **日期区间**：填「起始日期 / 结束日期」，结果 100% 落在区间内。
   **起始日期不能晚于结束日期**：日历控件会自动限制可选范围；若手动输入了非法区间，
   结束日期会自动对齐到起始日期并显示红色提示「起始日期不能晚于结束日期」。
3. **文件名关键字**：输入标题中的词（如「铁塔」「昆明」）做模糊匹配。

三者同时填写时取交集；点「重置」恢复默认云南视图并清空其它条件。

### 每条信息显示什么

- 四字段：**文件名 / 日期 / 来源 / 摘要**，缺失时显示「暂无摘要」「暂无来源」等明确占位；
- 地区标签（省 / 州市）、公告类型标签（**只作标签，不参与筛选**，所有类型公告都收录）；
- 「日期待核实」标签表示该条公告日期无法解析，但数据仍保留；
- 页面顶部：「数据更新时间」「数据截至」「总条数」「当前平台」；
- 页面底部：各数据源本次运行状态（条数 / 失败原因），单源失败不会影响其它源。

### 两个按钮

| 按钮 | 行为 |
| --- | --- |
| **跳转出处** | 打开库中保存的原始公告 URL；链接只允许 http/https，非法或缺失时按钮禁用并说明 |
| **下载源招标文件** | 按 L1~L4 档位下载，档位与文案直接显示在条目上 |

### 下载档位

| 档 | 你会得到 | 页面标注 |
| --- | --- | --- |
| L1 | 原站原始文件（保留中文名） | 原始文件 |
| L2 | 应用侧预存的源文件副本 | 源文件副本 |
| L3 | 详情页快照（HTML/文本） | 原站未提供文件下载，以下为详情页快照 |
| L4 | 按钮禁用，无文件 | 该来源不提供下载，请前往出处查看 |

L4 时**不会伪造文件、不会 404、不会点了没反应**，请改点「跳转出处」。
历史数据没有附件直链或快照文件，因此多数条目会显示 L4，这是诚实标注而非故障。

### 中文文件名与平台差异

- **Windows（Chrome/Edge）**：点击下载直接用原始中文名保存，不乱码。
- **macOS（Safari）**：Safari 对 `download` 属性支持有差异，页面会**在新标签打开目标文件**
  并给出明确引导：菜单「文件 → 存储为…」，文件名用提示里给出的中文名（UTF-8）。
  提示中还附有 RFC 5987 编码，供将来在线部署时设置下载头使用。
  这是有意的版本区分，不是故障。

## 3. 每天怎么更新（Windows 生产端）

> **终端 mac 不抓取、不生成数据**。数据只在 Windows 端每日生成一次，
> 通过一份文件通道送到终端，用户覆盖文件并刷新即可。

### 3.1 手动更新

双击仓库根目录的 `update.bat`。它按顺序完成：

1. 采集 4 个数据源 → 相关性校验 / 地区打标 / 去重 / 下载档位判定；
2. 落库 `output/bidding_history.db`（历史全量保留，不会按公告日期删除）；
3. 重新生成 `output/index.html`、`output/data.json`、`output/bidding_feed.xml`
   以及 `output/win/`、`output/mac/` 平台包（**原子写**：校验通过才替换，失败保留上一版）；
4. 尝试 `git push origin master`（**失败仅告警**，本地产物照常可用）；
5. 若设置了同步目录，复制 `output/` 过去。

### 3.2 设为每天自动运行（任务计划程序）

1. 打开「Windows 任务计划程序」→「创建基本任务」；
2. 名称：`铁塔招标信息每日更新`；触发器：**每天 08:00**（Asia/Shanghai）；
3. 操作：「启动程序」→ 程序或脚本填 `D:\AAAProject\AAAgithub\BiddingInformation\update.bat`；
   「起始于」填项目根目录 `D:\AAAProject\AAAgithub\BiddingInformation`；
4. 勾选「不管用户是否登录都要运行」（按需），完成。
5. 前提：已 `pip install -r requirements.txt`；`update.bat` 会自动优先使用项目内
   `venv` / `.venv`，否则用系统 Python；git 凭据已配置（push 失败不影响产物）。

### 3.3 把文件送到终端（四选一，零额外成本）

| 通道 | 每日步数 | 做法 |
| --- | --- | --- |
| 同步盘（坚果云 / 百度网盘 / 阿里云盘等） | **0 步** | 设置环境变量 `BIDDING_SYNC_DIR` 指向同步盘里的 `output` 目录，`update.bat` 自动复制；终端同步完成后刷新页面 |
| 文件传输助手 | 1 步 | 每天把 `output/index.html` 发过去并覆盖 |
| 局域网共享 / U 盘 | 1 步 | 复制 `output/` 覆盖 |
| 手动覆盖 | 1 步 | 同上 |

首次使用 1 步（加书签）；之后同步盘方案日常只需刷新已打开的页面。

## 4. 「数据截至」与新鲜度

- **数据更新时间**：本次产物生成时刻；**数据截至**：库中成功采集的最晚公告日。
- 数据截至超过 `offline.stale_days`（默认 **2** 天）时，页面会显示黄色提示。
- 离线 HTML **不会自动变新**：提示出现时，请从 Windows 端或同步盘重新取一次
  `output/index.html` 覆盖本地文件，然后刷新浏览器。
- 本期**不做任何消息推送**，用户主动打开页面才看到更新；断网也能看最近一次数据。

## 6. 常见问题

**Q：打开是空白或提示「内联数据解析失败」？**
A：确认 HTML 文件完整（没有只复制一半），改用 Chrome / Edge / Safari 打开。

**Q：为什么很多条目是 L4「无法下载」？**
A：历史数据没有附件直链，也没有保存过详情页快照。按规则不得伪造文件，
因此诚实标注为不可用。请点「跳转出处」到原站查看；开启 `download.prefetch`
并在生产端联网运行后，新数据会有更多 L1/L3 命中。

**Q：mac 上点下载只打开了新标签？**
A：这是 Safari 的有意降级行为，请按页面提示用「文件 → 存储为」保存，或改用 Chrome。

**Q：为什么页面还显示旧数据？**
A：离线文件不会自己更新。请重新覆盖 `output/index.html` 并刷新；页面顶部「数据截至」会变化。

**Q：看到「所有数据源本次均失败」提示？**
A：产物保留了上一版，数据仍可读。请检查 Windows 端网络与日志，稍后重跑 `update.bat`。
